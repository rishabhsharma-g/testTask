# 💻 2A Task – HTML, CSS & JavaScript Practice

A collection of web development practice tasks created while learning and improving skills in **HTML, CSS, JavaScript, and Git**.

This repository contains practical exercises covering basic to intermediate concepts of front-end web development, including semantic HTML, forms, accessibility, CSS layouts, animations, DOM manipulation, and JavaScript fundamentals.

## 📌 About The Project

**2A Task** is a learning and practice repository containing multiple web development exercises.

Each question is implemented as an individual HTML file, with separate CSS and JavaScript files wherever required.

The main purpose of this project is to build strong practical knowledge of front-end development through hands-on coding practice.

## ▶️ How To Run

1. Clone or download this repository.
2. Open the project folder in **Visual Studio Code**.
3. Select any `Q1.html`, `Q2.html`, etc.
4. Open the HTML file in a browser.

For a better development experience, **VS Code Live Server** can also be used.

## 🌿 Git Branching Practice

Git branching is also practiced in this repository.

Example branches:

```text
main
│
└── friends
```

The project includes practical Git exercises such as creating branches, switching branches, committing changes, merging branches, and resolving merge conflicts manually.

## 🔀 Merge Conflict Practice

A merge conflict was intentionally created by making changes to the same file in different branches.

The conflict was manually resolved using:

```bash
git merge friends
```

After resolving the conflict:

```bash
git add Git67.html
git commit -m "Resolved merge conflict"
```
